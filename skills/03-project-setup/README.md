# Project setup and orientation

Give a project its profile and structure, and learn where everything lives.

Each subfolder here is one skill. In Muse, call it by name, for example `/core-project-profile`. The full map,
with every category and the quick finder, is [SKILLS-MAP.md](../../SKILLS-MAP.md). This file is generated by
`node tools/skill-map.mjs`.
