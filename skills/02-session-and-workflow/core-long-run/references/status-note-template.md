# Status-note template

Write one note per task in `paths.handoff`, right after the task.

```markdown
## Status: <task> (YYYY-MM-DD HH:MM)
Done: <one line>
Evidence: <command + result, or file>
Next: <one line>
```

- Exactly 3 lines after the title: done, evidence, next.
- A stopped task still gets a note: done names what stopped it and why.
- Write the note before any checkpoint save or run stop.
